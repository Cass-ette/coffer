# 钱包费用透明化与按次租能量

用户于 2026-10-11 授权扩展钱包：选择高效付费方式、比较总费用、按实际执行展示支出，操作保持简单。此授权扩展原计划「不做能量管理」的范围，仅限转账所需的按次购买，不做质押或通用 DApp 签名。后续用户另行确认官方 GasFree 独立钱包，见 [GasFree 计划](2026-10-11-wallet-gasfree.md)。

## 实施顺序

1. 资源估价：扣除可用能量，正确处理质押/委托及免费带宽；区分预计 TRX 消耗与合约能量执行上限。解析链上回执，显示实际费用。先红测试，再实现，全量回归并独立中文提交。
2. 按次租赁：TronSave v2 无 API key 的 signed-transaction 流程，默认一小时，仅购买本次资源缺口。只读比价包含租金、付款带宽和转账带宽。私钥始终本地签名，固定服务商收款地址、验证实际 protobuf、禁止远程签名接口。报价过期或成本上涨重新确认；资源未到/支付未知时不得重复购买或继续转账。
3. 转账界面：直接付费与租能量可选择，总成本与明细可见，默认推荐较便宜的可执行方案。认证后按确认的方案执行，保存公开交易哈希供中断后查询；真实回执展示实际费用和失败状态。全量测试、App/CLI 构建，补充验收记录。

## 费用语义与边界

- 直接付费按链上实际消耗收费；fee_limit 是执行预算，不是预扣或固定手续费，且包含自有/委托能量折合价值，不能用净 TRX 费用代替。
- 租赁按订单数量、租期收费，未用完的资源不承诺退款。界面同时展示租期、资源数量、固定租金与其余网络费用，不宣称严格按实际消耗能量结算。
- 下单不需要给服务商预充值。失败、超时、锁屏和重启需保留可查询的支付/转账哈希，不自动重复付费；无用户认证不签名、不下单。
- 所有主网开发核查只读；真实购买、转账由用户在 App 中核对并认证。原冷备份和恢复演练约束继续适用。
- 报价有效期 90 秒。合约能量执行预算加 20% 余量；预计费用与按当前资源计算的最高约支出分开展示，授权前余额须能覆盖后者。
- 中断记录使用独立 JSON 文件原子保存，仅含公开付款哈希、到期时间、租金、订单号与回执；先保存成功才能提交。查到失败也展示实际费用。查询错误保留待确认状态，不用空响应直接清记录。
- 交易已过期且完整节点与固化链均查无记录，并且固化区块时间超过过期时间 60 秒，才允许重新估价。付租后资源尚不足不重复购买，可重新确认按当前资源计算的直接转账费用。
