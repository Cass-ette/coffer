# 服务器凭证与创建入口

用户在 GasFree 开发期间追加：专门存储服务器 SSH 密码，并优化“＋”的条目选择，后续向更完整的安全工具扩展。

本次交付：新增服务器条目（主机、端口、用户名、密码/私钥/本机 SSH agent、私钥口令、网络位置），详情隐藏敏感字段，支持复制不含凭证的 SSH 命令。原 SSH 密钥条目保留用途与内容。新增可搜索、按用途分组的创建选择页，编辑器类型选择不再挤在一行。

先补磁盘格式与搜索隔离测试，再实现 Core / GUI / CLI 兼容。服务器作为新 payload case，仍使用 `{ "server": { "_0": ... } }`；不改变既有 payload、vault 版本、加密与备份，不批量迁移真实库。CLI 仅展示服务器元数据，凭证在 App 编辑，避免通过命令参数新增秘密。

全量测试只增不减（当前基线 165），App/CLI 构建通过后独立中文提交。用户手测创建、保存、解锁后读取及复制；不自动 SSH 连接或执行远程命令。

后续产品方向：以凭证管理为基础，逐步建设受控访问工具与安全检查。自动连接、SSH agent 集成、轮换、审计提醒等另行设计，不在此任务中隐式启用。

## 实施结果

- Core 169 项回归全通过，包含服务器编码 `_0` 结构、未知数据保留、凭证搜索隔离、命令不含秘密与注入输入拒绝。
- App 与 CLI 最终构建通过。App 支持服务器创建/编辑、密码生成、隐藏私钥编辑、详情与快捷复制；CLI 显示元数据并隐藏凭证。
- “＋”改为分类卡片与搜索，编辑器改用分组菜单选择类型，已有条目不迁移。
- 待用户手测：创建服务器 → 保存 → 锁定/解锁后读取 → 查看/复制密码；SSH 私钥、端口错误、分类搜索与取消编辑。
- 钱包真实转出及冷备份演练仍按原验收要求独立完成。
